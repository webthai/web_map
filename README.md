# 🗺️ แผนที่ออฟไลน์ (Offline Map App)

เว็บแอปแผนที่ที่ใช้งานได้ทั้งออนไลน์และออฟไลน์ ดาวน์โหลดแผนที่ + ข้อมูลถนนล่วงหน้าเพื่อใช้งานตอนไม่มีเน็ต บันทึกหมุดสถานที่ซิงก์กับ Google Sheets

## ⚠️ สิ่งที่ควรรู้ก่อนเริ่ม (ข้อจำกัดของระบบ)

- **ไม่ใช่ Google Maps** — ใช้แผนที่จาก OpenStreetMap (ฟรี ถูกกฎหมายสำหรับดาวน์โหลดเก็บออฟไลน์ ต่างจาก Google Maps ที่ห้ามทำแบบนี้)
- **นำทางออฟไลน์เป็นแบบประมาณการ** — ใช้กราฟถนนอย่างง่าย ไม่มีข้อมูลจราจร/ป้ายจำกัดความเร็ว/ทางเดียวครบถ้วนเหมือนแอปนำทางเชิงพาณิชย์ เหมาะกับ "พอมีเส้นทางให้ไปได้" ไม่ใช่เส้นทางที่ดีที่สุดเสมอไป
- **พื้นที่ดาวน์โหลดควรอยู่ระดับอำเภอ/ตำบล** — ถ้าดาวน์โหลดกว้างเกินไปหรือซูมละเอียดเกินไป จะกินพื้นที่เก็บข้อมูลในเครื่องมาก โดยเฉพาะ iPhone รุ่นเก่าที่มีพื้นที่เก็บข้อมูลจำกัด
- ต้อง**มีอินเทอร์เน็ต**ตอนสมัคร/เข้าสู่ระบบครั้งแรก และตอนดาวน์โหลดพื้นที่ออฟไลน์

## 📁 ไฟล์ทั้งหมดที่ต้องอัปโหลดขึ้น GitHub

อัปโหลดไฟล์เหล่านี้ไว้ที่ **root ของ repository** (ไม่ต้องอยู่ในโฟลเดอร์ย่อย):

```
index.html   ← หน้าเว็บแอปหลักทั้งหมด (HTML+CSS+JS รวมไฟล์เดียว)
sw.js        ← Service Worker (จำเป็นต้องแยกไฟล์ตามข้อกำหนดของเบราว์เซอร์)
README.md    ← ไฟล์นี้ (ไม่บังคับต้องอัป แต่แนะนำให้เก็บไว้)
```

`Code.gs` **ไม่ต้อง**อัปขึ้น GitHub — เป็นโค้ดฝั่ง Google Apps Script ต้องวางใน Apps Script Editor ต่างหาก (ดูขั้นตอนด้านล่าง)

---

## 🚀 ขั้นตอนที่ 1: สร้างฐานข้อมูล (Google Sheets + Apps Script)

1. ไปที่ [sheets.google.com](https://sheets.google.com) สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น "Offline Map DB"
   (ไม่ต้องสร้างชีตย่อยหรือหัวตารางเอง — โค้ดจะสร้างให้อัตโนมัติตอนรันครั้งแรก)
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดตัวอย่างทั้งหมดในไฟล์ `Code.gs` ที่เปิดขึ้นมา แล้ววางโค้ดจากไฟล์ `Code.gs` ที่แนบมาให้แทน
4. กดปุ่ม 💾 บันทึก (Ctrl+S)
5. กด **Deploy > New deployment**
6. ที่ช่อง "Select type" กดรูปเฟือง ⚙️ เลือก **Web app**
7. ตั้งค่า:
   - **Execute as:** `Me (อีเมลของคุณ)`
   - **Who has access:** `Anyone`
8. กด **Deploy** → ระบบอาจให้กด "Authorize access" ยืนยันสิทธิ์ (เลือกบัญชี Google ของคุณ แล้วกด "Advanced" > "Go to (ชื่อโปรเจกต์) (unsafe)" ถ้าเจอหน้าเตือน — ปลอดภัยเพราะเป็นโค้ดของคุณเอง)
9. คัดลอก **Web app URL** ที่ได้ (รูปแบบ `https://script.google.com/macros/s/xxxxxxx/exec`) — จะใช้ในขั้นตอนถัดไป

### ⚠️ สำคัญมาก: ทุกครั้งที่แก้โค้ด Code.gs ต้อง Deploy ใหม่
ถ้าคุณแก้ไข `Code.gs` ในอนาคต การกดบันทึกอย่างเดียว **ไม่ทำให้เว็บแอปที่ deploy ไปแล้วอัปเดต** ต้องทำดังนี้ทุกครั้ง:
`Deploy > Manage deployments > กดไอคอนดินสอ (Edit) > Version: เลือก "New version" > Deploy`

---

## 🚀 ขั้นตอนที่ 2: ใส่ URL ลงในเว็บแอป

เปิดไฟล์ `index.html` ด้วยโปรแกรมแก้ไขข้อความ (เช่น Notepad, VS Code) ค้นหาบรรทัดนี้ (อยู่ใกล้ๆ ต้น `<script>`):

```js
const DEFAULT_SCRIPT_URL = ""; // <-- วาง URL หลัง deploy Apps Script ตรงนี้
```

แก้เป็น:

```js
const DEFAULT_SCRIPT_URL = "https://script.google.com/macros/s/xxxxxxx/exec";
```

(วาง URL ที่คัดลอกมาจากขั้นตอนที่ 1 ข้อ 9) แล้วบันทึกไฟล์

> ถ้าไม่แก้ตรงนี้ก็ยังใช้ได้ — เว็บแอปจะถามให้กรอก URL เองครั้งแรกที่เปิดใช้งาน และจำไว้ในเบราว์เซอร์นั้นๆ แต่การแก้ค่าคงที่ในโค้ดจะสะดวกกว่าเพราะไม่ต้องกรอกซ้ำทุกเครื่อง/เบราว์เซอร์

---

## 🚀 ขั้นตอนที่ 3: อัปโหลดขึ้น GitHub Pages

1. สร้าง repository ใหม่บน [github.com](https://github.com) (public repository)
2. อัปโหลดไฟล์ `index.html` และ `sw.js` ขึ้น repository (ลากไฟล์วางในหน้าเว็บ GitHub ได้เลย หรือใช้ Git)
3. ไปที่ **Settings > Pages**
4. หัวข้อ "Source" เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1-2 นาที จะได้ลิงก์เว็บแอปรูปแบบ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`
6. เปิดลิงก์นั้นบนมือถือ/คอมพิวเตอร์ได้เลย

### 📱 ติดตั้งเป็นแอปบนหน้าจอโฮม (แนะนำ เพื่อให้ออฟไลน์ทำงานได้ดีที่สุด)
- **iPhone (Safari):** เปิดลิงก์ > แตะปุ่มแชร์ 🔺 > "เพิ่มไปยังหน้าจอโฮม"
- **Android (Chrome):** เปิดลิงก์ > เมนู ⋮ > "ติดตั้งแอป" หรือ "เพิ่มไปยังหน้าจอโฮม"

## ✅ วิธีใช้งาน

1. **สมัครสมาชิก** ครั้งแรก (คนแรกที่สมัครจะได้สิทธิ์แอดมินอัตโนมัติ) — ต้องมีเน็ตตอนสมัคร/ล็อกอิน
2. หรือกด **"ใช้งานแบบไม่ล็อกอิน"** ถ้าต้องการใช้แค่ในเครื่องนี้โดยไม่ซิงก์ข้อมูล
3. แท็บ **📍 หมุด** — ปักหมุดสถานที่ที่ต้องการจำไว้
4. แท็บ **⬇️ ดาวน์โหลด** — ซูมแผนที่ไปยังพื้นที่ที่ต้องการ (แนะนำระดับอำเภอ/ตำบล) กด "เริ่มดาวน์โหลด" เพื่อเก็บแผนที่ + ข้อมูลถนนไว้ใช้ออฟไลน์
5. แท็บ **🧭 เส้นทาง** — เลือกจุดเริ่มต้น/จุดหมาย (แตะบนแผนที่ หรือใช้ตำแหน่ง GPS) แล้วกด "คำนวณเส้นทาง"
   - มีเน็ต → ใช้เส้นทางแม่นยำจากระบบออนไลน์ (OSRM)
   - ไม่มีเน็ต → ใช้เส้นทางประมาณการจากข้อมูลถนนที่ดาวน์โหลดไว้ (ต้องดาวน์โหลดพื้นที่นั้นไว้ล่วงหน้า)

## 🗂️ โครงสร้างข้อมูล (Google Sheets)

สร้างอัตโนมัติเมื่อรันครั้งแรก ไม่ต้องตั้งค่าเอง:

**Users**: `id, username, passwordHash, role, token, createdAt`
**Places** (หมุดสถานที่): `id, userId, name, lat, lng, note, createdAt, updatedAt`

ข้อมูลแผนที่/ถนนสำหรับออฟไลน์ **ไม่ได้เก็บใน Sheets** (ไฟล์จะใหญ่เกินไป) แต่เก็บไว้ใน IndexedDB ของเบราว์เซอร์แต่ละเครื่องแทน — หมายความว่าต้องดาวน์โหลดพื้นที่แยกในแต่ละอุปกรณ์ที่ต้องการใช้ออฟไลน์

## 🔒 ความปลอดภัย

- รหัสผ่านถูกเข้ารหัสด้วย SHA-256 ที่ฝั่งเบราว์เซอร์ก่อนส่งไป ไม่มีการเก็บรหัสผ่านตัวจริง
- ระบบตรวจสิทธิ์ (ผู้ใช้ทั่วไปแก้ไข/ลบได้เฉพาะหมุดของตัวเอง, แอดมินเห็น/จัดการได้ทุกคน) ถูกบังคับที่ฝั่ง Apps Script เสมอ ไม่ใช่แค่ซ่อนปุ่มในหน้าเว็บ
